The week's work:

This week I created CSS files for each individual JSX file. This allowed me to be precise with the styling of each component and page.

At first, I used regular CSS. However, I struggled to find a good naming system because the class names quickly became very long. I mainly used Flexbox instead of CSS Grid because I was already familiar with Flexbox from the second semester. Grid seems more rigid, but also more structured and intuitive in some situations.

I continued focusing on a dark theme for the website. I have not decided whether I want to add a light mode later, but it could be a possible improvement if I have time.

Thoughts and reflections:

Looking back, I later learned about CSS Modules, which solved the problem of long and specific CSS class names. I renamed my CSS files to use modules, which allowed me to use simpler class names in each file without worrying about naming conflicts across the whole project.

This week made me understand why styling structure matters in React projects. As the project grows, CSS can quickly become messy if there is no clear system.
