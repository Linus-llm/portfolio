The weeks work:

Start of the frontend part of the portfolio project. I started by making a Figma sketch of the entire layout of my project. So that means I have sketched:
1. Home page
2. Login page
3. Sign up page
4. Overview of collection page
5. Overview of items in collection page
6. New collection page
7. New Item page

Thoughts and reflections:
I decided to go with a dark-themed layout because I personally like the style and find it more aesthetically pleasing.

Before starting the actual implementation, I searched for inspiration and also used ChatGPT to generate small layout sketches. This helped me get ideas for colors and general visual direction. For the actual layout, I took inspiration from DBA, especially for the pages where users create new content. The login and sign-up pages came more naturally, since they are simpler pages.

For the page that shows a user's collections, I looked at similar collector websites, including an online Pokémon collection website, to see how they displayed lists of collections and items.

Later during the project I noticed that the new item page that I had created initially was meant to just stay in the navbar and from there you would choose in which collection it would go.
This has been replaced with a new item page that is only available when the user has clicked on a specific collection.
