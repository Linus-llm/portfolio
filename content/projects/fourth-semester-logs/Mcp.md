MCP:

MCP is a protocol for communication between the client and the server for ai's. 
MCP are a great way for ai's to gain access to tools that others have built. A great example of this is Figma's mcp server which gives access to the client to send UI changes and live building to Figma. It can extract layout data that can be used when coding and designing your own frontend. 

MCP could be used in our project between our frontend and figma. It could be a great way for keeping a standard and a source of thruth for the design. 

This is just a thought but lets say that you have an integrated LLM on your application if that LLM then has access to lets say the weather through an MCP server to dmi then it could live update instead of searching on google and taking different sources everytime you ask it.
